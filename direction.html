direction

Four years from now, I see myself working in a game studio as a junior game developer, contributing to both the design and technical sides of production.

My background as an artist gives me a strong sense of composition, and atmosphere, while HBO-ICT is building the logical and technical foundation to bring those ideas to life.

I recognise that moving from art to ICT is a risk, but curiosity has always been my strongest drive. By then, I hope to have a portfolio of completed projects, experience in a team environment, and the confidence to keep developing as a designer and programmer.

What is Software Engineering?

Software engineers design, build, test and maintain software. A normal week includes writing code, fixing bugs, reviewing teammates' code, writing tests, and talking with designers or clients about what the software should do. They usually work in a team using tools such as Git.

Why I chose Software Engineering

Data Science focuses on collecting and analysing data to find patterns and support decisions, using skills like statistics and tools like Python. I prefer building something people can use and experience, like a game, over analysing data

Data Science vs Software Engineering

Software Engineering Data Science
Main goal Design and build working software Find patterns and answers in data
Typical tasks Writing code, fixing bugs, testing it Collecting and cleaning data, analysing it
Tools and languages Java, JavaScript, Python, Git, game engines Python, statistics and machine learning
Main skills Programming, logic,teamwork Statistics, maths, analysing
Result of the work An app, website or game people can use reports, predictions, models
Example jobs Software developer, game developer, web developer Data analyst, data scientist, machine learning engineer
